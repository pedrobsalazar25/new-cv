# Uploaded Images & Media Directory

Place all your image assets (PNG, JPG, WebP, SVG, GIF) directly inside `/public/images/`.

### How to reference your uploaded images in code and the CMS:
Any file placed in `/public/images/example.jpg` is served directly at:
- `/images/example.jpg`

### Examples:
- `/images/hero-bg.jpg`
- `/images/project-preview.png`
- `/images/logo.png`
